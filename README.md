# CodSoft Task 2 – Calculator

## 📌 Project Overview

This project is **Task 2 of the CodSoft Python Programming Internship**.

The **Calculator Application** is a Python-based application that performs basic mathematical operations through a simple and user-friendly interface.

## 🚀 Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear/Reset option
* Simple and easy-to-use interface

## 🛠️ Technologies Used

* **Python**
* **Tkinter** – Graphical User Interface

## 🎯 Objective

The main objective of this task is to create a simple calculator application and improve understanding of Python programming and GUI development.

## 📚 Learning Outcome

Through this task, I learned:

* Python functions
* GUI development using Tkinter
* Event handling
* User input handling
* Basic mathematical operations
